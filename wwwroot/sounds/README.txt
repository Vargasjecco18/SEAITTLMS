The sound of a notification
===========================

Put the sound you want in this folder and call it:

    notification.mp3     (or notification.ogg, notification.wav, notification.m4a)

It is played when a new message or notification arrives while a page is open. Keep it short (one or two seconds). The system looks for the file the first time it needs it,
so after you add it, reload the page once.

There is no file here at first: the system then plays two short tones that the browser makes by itself.

Use a sound you are allowed to use (one you made, or one with a licence that lets you use it in a school system). A sound of a video on YouTube can't be taken from the
website by the system; if you have the right to use it, download it yourself and save it here as notification.mp3.
